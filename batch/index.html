What it does

Point it at a folder

It walks the folder and everything nested inside it, converts every .pub file it finds, and rebuilds the same folder structure on the way out. One pass, unattended.

Windows, macOS and Linux

The same engine as this website. Publisher never ran on a Mac, so if your archive has outlived the computer that made it, this still opens it.

A list of what needs a person

A spreadsheet or a page you can send on, naming every file, what came out, and what was lost — so a folder of four hundred becomes a list of the nine that matter.

Nothing is uploaded, again

It has no network access at all. Same argument as the website, same reason: your member lists and class lists are nobody else’s business.

Try it on one file first

Convert one of your own files on the front page before you go near the folder. It is the same engine, so what you see there is what the batch runner will do to the rest — including the files it cannot read, which it names rather than quietly skipping.

Pubshift is open source under the MPL-2.0, so the converter outlives whatever happens to us. If it does not work on your files it will not work on them in bulk either, and we would rather you found that out in ten seconds on the front page.

Nothing you convert here is sent to us. Your file is opened by this page on your own computer. There is no upload, no account and no copy on any server of ours. Privacy
