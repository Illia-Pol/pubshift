# Метрики

## Зачем этот файл
Главная ценность запуска — не выручка, а первое проверенное число про дистрибуцию за всю историю проекта.
Двадцать шесть исследовательских заходов упирались в «до него не дойти». Этот запуск отвечает на вопрос
фактом. Чтобы ответ существовал, нужен **фиксированный знаменатель**: сколько людей увидели, сколько
попробовали, сколько заплатили.

## Что записывать, начиная с первого дня
| Показатель | Как считать |
|---|---|
| Визиты на страницу | По источнику: поиск, ссылка из сообщества, прямой заход |
| Загрузили файл | Доля от визитов |
| Конверсия удалась | Доля от загрузивших. Ошибки логировать по типу |
| Скачали результат | Доля от успешных |
| Заплатили | Доля от скачавших, когда касса появится |
| Вернулись со вторым файлом | Признак, что продукт реально нужен |

## Что записывать про файлы
Для каждой неудачной конверсии — тип объекта, на котором сломалось. Это и есть план разработки, и он
важнее любого отзыва.

## Честные пороги
Определить заранее, до запуска, и записать сюда:
- Сколько визитов за первые две недели означает, что канал работает.
- Какая доля успешных конверсий означает, что продукт годен к продаже.
- При каком результате проект закрывается.

Порог, назначенный после того, как увидел цифры, — это не порог.
