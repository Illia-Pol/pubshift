Credits and licences

Pubshift did not work out how to read Microsoft Publisher files. The Document Liberation Project did, over years, and published the result as free software. This page says whose work is in the converter, and how to get the source for the part that runs in your browser.

What is in the converter

  • libmspubMPL-2.0

    Reads the Publisher file format. This is the part that makes any of this possible, and it is not ours.

  • librevengeMPL-2.0

    The document model libmspub reports into, and the reader for the OLE container a .pub file lives in.

  • zlibzlib licence

    Decompresses the streams inside a .pub file.

  • BoostBSL-1.0

    Header-only utilities used by the parser.

  • Emscripten, LLVM libc++ and muslMIT / Apache-2.0 with LLVM exception / NCSA

    Compile the C++ parser to WebAssembly and give it a standard library inside your browser.

  • ICUUnicode licence

    Not linked in, but the character-encoding tables that turn old Windows codepages into readable text were dumped from ICU so the answers match rather than approximate.

Getting the source

The file your browser downloaded to do the conversion, pubshift.wasm, contains libmspub 0.1.6 and librevenge 0.0.6, compiled. Both are covered by the Mozilla Public License 2.0, which says that anyone given the compiled form must be able to get the source it was built from. So:

  • •The complete corresponding source archive for this build has not been uploaded yet. Until it is, ask and it will be sent to you at no charge; the licence allows charging no more than the cost of distribution, and there is no cost.
  • •Pubshift’s own code is at github.com/Illia-Pol/pubshift, also MPL-2.0.
  • •The licence text: Mozilla Public License 2.0. The full component list, with commit hashes and checksums: third-party notices.

The build running on this page is 3e22a766f4461d60943743b0e159b83b… — the SHA-256 of the WebAssembly file, so you can tell which source matches what you were served.
